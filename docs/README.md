# TechonERP Documentation Home

Welcome to the official TechonERP documentation library. This is the entry point for engineers, operators, QA, architects, and contributors working on the desktop ERP product.

TechonERP is an offline-first Electron ERP for retail and service businesses, supporting standalone and multi-PC synchronized operation.
