# ERP Release Checklist

## Core Flow

* [ ] Login works
* [ ] Create 1 sale (full payment)
* [ ] Create 1 sale (partial payment)
* [ ] Create 1 purchase
* [ ] Perform 1 return (sales or purchase)

## Reports

* [ ] Profit & Loss loads correctly
* [ ] Balance Sheet loads correctly

## Backup & Restore

* [ ] Create backup
* [ ] Restore backup on test copy
* [ ] Verify data integrity

## Sync (if enabled)

* [ ] Sync between two devices
* [ ] No duplicate or missing records

## Final Check

* [ ] No console errors in production mode
* [ ] UI loads without crashes
