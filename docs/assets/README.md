# Documentation Assets

## Purpose

This folder stores visual and media assets used by TechonERP documentation.

## Intended Contents

- Architecture diagrams
- Entity-relationship (ER) diagram exports
- Workflow and sequence diagram images
- Screenshots (UI, settings, installation)
- Icons and branding assets used in docs
- Other documentation media (PDF exports, etc.)

## Usage

Reference assets from markdown using relative paths from the document that embeds them (e.g. `../assets/system-architecture.png` from a category folder).

## Note

Binary assets are not versioned in this placeholder. Add images and diagrams here as the documentation library grows.
