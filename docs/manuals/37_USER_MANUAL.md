# Getting Started

Before using TechonERP

- Ensure the application is installed.
- Confirm login credentials.
- Verify printer availability.
- Confirm database connectivity (Multi-PC mode).
- Ensure synchronization is enabled if required.

---

# Logging In

Steps

1. Open TechonERP.
2. Enter Username.
3. Enter Password.
4. Click **Login**.
5. Wait for Dashboard.

If login fails

- Verify username.
- Verify password.
- Contact administrator if necessary.

# Creating a Sales Invoice

Steps

1. Open Sales Module.
2. Select Customer.
3. Add Products.
4. Enter Quantity.
5. Apply Discount (if authorized).
6. Verify totals.
7. Save Invoice.
8. Print Invoice (optional).

Always verify invoice details before saving.

---

# Purchase Entry

Steps

1. Open Purchase Module.
2. Select Supplier.
3. Add Purchased Products.
4. Enter Quantity.
5. Enter Cost Price.
6. Save Purchase.

Inventory updates automatically after successful purchase recording.

- Synchronization occurs automatically.
- Users normally do not need to perform manual actions.

If synchronization appears delayed

- Wait briefly.
- Verify network connection.
- Contact administrator if the issue persists.

# Frequently Asked Questions

### I cannot log in.

Verify username and password. Contact the administrator if necessary.

---

### A product cannot be found.

Search using product code or product name. Confirm the product has not been archived.

---

### Inventory quantity looks incorrect.

Review recent purchases, sales, and inventory adjustments. Contact the administrator if discrepancies remain.

---

### Synchronization appears delayed.

Verify network connectivity and allow time for automatic synchronization. If unresolved, notify technical support.

---

### Reports do not show expected data.

Verify date filters and search criteria before regenerating the report.

---

# Best Practices

Users should

- Save work frequently.
- Verify information before saving.
- Avoid duplicate entries.
- Record transactions immediately.
- Log out after use.
- Report unusual behavior promptly.

Following best practices improves overall system reliability.

---

# Troubleshooting

If problems occur

1. Read the displayed error message.
2. Retry the operation.
3. Restart the application if necessary.
4. Contact the system administrator.

Do not modify system files or database records manually.
